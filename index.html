About CRYPTO

Cryptographic Key Exchange Authentication enables secure communication by allowing two or more entities to establish a shared secret key. This key is later used for encryption and secure data transfer. The project focuses on secure authentication using modern cryptographic techniques integrated with a web application — covering registration, login, AES-GCM key generation, and an encrypted file vault with controlled sharing.

In legacy systems, key exchange mechanisms often rely on static keys or weak authentication models, leaving them vulnerable to man-in-the-middle attacks, replay attacks, and key compromise. This rebuild favours per-session key material, authenticated encryption (AES-GCM), and clear audit trails of login activity and key generation.
